This repository contains a project that involves creating documentation and an HTML page to show the flow structure of Jupyter notebooks.

## Project Overview

This project aims to document the entire process of the project and create an HTML page to visually represent the flow structure of the Jupyter notebooks. The documentation includes detailed explanations of the project's components and how they interact with each other.

## Installation

To set up the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/your-repo.git
   ```

2. Navigate to the project directory:
   ```bash
   cd your-repo
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

To use the project, follow these steps:

1. Open the Jupyter notebooks located in the `notebook` directory.
2. Run the cells in the notebooks to see the flow structure.
3. View the HTML page to get a visual representation of the notebook flow.

## Documentation

The documentation is divided into several sections:

1. **Data Ingestion**: Explains how data is ingested into the system.
2. **Text Loaders**: Describes the different text loaders used in the project.
3. **PDF Loaders**: Details the PDF loaders and their usage.
4. **Flow Structure**: Provides a visual representation of the notebook flow.

## HTML Page

The HTML page is located in the `docs` directory. It provides a visual representation of the flow structure of the Jupyter notebooks. To view the HTML page, open the `index.html` file in a web browser.
